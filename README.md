⚖️ Assistente Jurídico Educacional

Um chatbot jurídico educacional desenvolvido em Python utilizando inteligência artificial local através do Ollama e do modelo Llama 3.2 3B.

📚 Sobre o projeto

O Assistente Jurídico Educacional foi desenvolvido como um projeto de estudo com o objetivo de explorar conceitos de programação e inteligência artificial.

O projeto permite que o usuário escolha uma área do Direito e faça perguntas para uma inteligência artificial especializada em Direito brasileiro.

🤖 Tecnologias utilizadas
Python
Ollama
Llama 3.2 3B
✨ Funcionalidades
Identificação do usuário
Seleção da área jurídica
Respostas geradas por inteligência artificial
Streaming das respostas
Histórico da conversa
Comando para limpar o histórico
Comando para consultar a área atual
Comando para encerrar o programa
Execução utilizando inteligência artificial local
⚙️ Como executar
1. Instale o Python

É necessário ter o Python instalado no computador.

2. Instale o Ollama

Instale o Ollama e baixe o modelo Llama 3.2 3B.

3. Clone o repositório

git clone URL_DO_REPOSITORIO

Entre na pasta:

cd chatbot-programacao

4. Instale a biblioteca Python

pip install -r requirements.txt

5. Execute o programa

python main.py

💬 Exemplos de perguntas

O usuário pode selecionar diferentes áreas do Direito e fazer perguntas como:

O que é responsabilidade civil?
O que é legítima defesa?
Qual a diferença entre dolo e culpa?
O que é uma Constituição?
O que é jurisprudência?
⚠️ Aviso importante

Este projeto possui finalidade exclusivamente educacional.

As respostas são geradas por um modelo de inteligência artificial local e podem conter erros ou informações imprecisas.

O chatbot não substitui a consulta à legislação atualizada, jurisprudência oficial, doutrina especializada ou orientação de um advogado.

🧠 Limitações da V1

O projeto utiliza o modelo Llama 3.2 3B executado localmente. Modelos menores podem apresentar erros ou informações jurídicas imprecisas.

Por esse motivo, as respostas devem ser utilizadas como apoio aos estudos e sempre verificadas em fontes jurídicas confiáveis.
